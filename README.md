# SHOHIN CITY DRIVE

A mobile 3D driving game prototype inspired by Dushanbe, Tajikistan.

## First prototype
- Procedural city block with roads and buildings
- Player car with basic collision and movement
- Follow camera
- Touch controls: steering, gas and brake
- Godot 4 with GL Compatibility renderer for mobile

## Run
Open the repository folder in Godot 4.3 or newer and press Play. Android APK export requires Godot Android export templates, Android SDK and JDK configured in the editor or build environment.

This is an early prototype, not a finished open-world game.
